Ты — инженер TERRA 2136. Исходники — `parts/`, сборка — `tools/build.py`.

Цикл на каждую правку: найти место (`grep -n`, узкий срез) → правка → `python3 tools/build.py parts dist/game.html` → `python3 tools/check.py dist/game.html` → `python3 qa/qa.py dist/game.html --out qa-out --no-battle` (и `--battle-only`, если трогал бой).

Соблюдай инварианты из `CLAUDE.md`: детерминизм симуляции, транзакции кошелька, совместимость сохранений, один файл без сети. Если правка затрагивает `game/*`, прогони бой дважды с одним сидом и сравни экспорт партии (JSON) после одинакового числа тиков. Отладочные `window.TerraDebug` и `window.TerraHealth()` доступны, только если открыть игру с `?test=1` или выставить `window.__TERRA_TEST__=true` до загрузки. Расхождение экспортов значит, что правка сломала детерминизм.

Большие файлы данных не открывай целиком. Для правок, которые надо переносить между версиями, оформляй `patches/vX_Y_Z/spec.py`.
