# Визуальная проверка

## Прогон

```
python3 qa/qa.py dist/TERRA2136_PLAY.html --out qa-out --no-battle                     # меню: mobile + desktop, ~1–2 мин
python3 qa/qa.py dist/TERRA2136_PLAY.html --out qa-out-b --battle-only --viewports mobile --battle-seconds 6
```
Рендер идёт на SwiftShader (без GPU): кадры медленные, FPS в отчёте не отражают телефон. Для производительности смотри реальное устройство.

## Как читать `report.json`

- `problems` пуст и `QA RESULT: PASS` — порог пройден.
- `launch_first_screen: true` — кнопка «В БОЙ» видна на первом экране штаба без прокрутки.
- `scroll_screens` — сколько экранов прокрутки у раздела; рост без причины = регрессия.
- `tinyText`, `smallTargets`, `clipped` — не блокируют PASS, но каждый новый элемент в этих списках требует объяснения.
- `battle.dock_stable: true` — нижняя панель боя не пересоздаёт кнопки под пальцем.

## Как смотреть скриншоты

Смотри не «красиво ли», а по списку:
1. Главное действие экрана видно сразу и оно одно.
2. Нет наложений, обрезанного текста, пустых дыр, элементов у самого края.
3. Иконки одного семейства; активное состояние отличимо не только цветом.
4. Тексты — для игрока (без DEV-кодов, англицизмов, «прототип»).
5. До/после: собери контакт-лист (`PIL`, по 5 скриншотов в ряд) и сравни одинаковые экраны. Для мелких деталей обрезай и увеличивай нужный участок, а не смотри весь экран целиком.

Каждую находку записывай «экран · что · где на скриншоте · как исправить».
