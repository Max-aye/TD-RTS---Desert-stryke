# Промты и цели для Claude Code на Opus 5.5

## Настройки сессии

- Модель: Opus 5.5. Уровень effort по умолчанию — `medium`; `high` для ролей `game-designer` и `tech-artist` (уже прописано в их файлах). `xhigh`/`max` включать только если на конкретной задаче `high` заметно ошибался.
- Длинные задачи — через `/goal` в режиме auto, чтобы ход не ждал подтверждений.
- Проект: папка с `CLAUDE.md`, `.claude/`, `tools/`, `qa/`, `patches/`, `docs/` и `parts/` (создаётся `split.py`).

## Как ставить задачу

Модель лучше всего работает, когда задача описана целиком и сразу. Пять полей:

```
Цель: что должно получиться для игрока.
Контекст: какие экраны/файлы/данные затронуты (или «найди сам по CLAUDE.md»).
Границы: что нельзя трогать (симуляция, формат сохранения, данные баланса…).
Проверка: какими командами доказать результат.
Финиш: одна строка, по которой видно, что задача закрыта.
```

Не добавляй «перепроверь себя», «будь внимателен», «подумай хорошенько» — модель и так проверяет результат, а такие фразы только удлиняют ходы. Для визуальных задач перечисляй конкретные приёмы, которых не должно быть, — общее «без шаблонного вида» не работает.

## Добавка в начало длинной автономной сессии

Вставь один раз, первым сообщением (или в `CLAUDE.md`, если все сессии автономные):

```
Работа идёт без меня. Не заканчивай ход сводкой с объявлением следующего шага — сразу делай этот шаг. Не предлагай «продолжить, если я не против» и не перечисляй решения для меня, если они не блокируют работу: запиши рекомендацию в docs/TASKS.md и продолжай с тем, что от неё не зависит. Короткие статусы пиши в том же сообщении, что и следующий вызов инструмента. Останавливайся только если без меня дальше нельзя или нужно разрушительное действие.
```

## Короткие промты для ролей

```
@"qa-reviewer (agent)" проверь текущую сборку против v0.95: все находки списком с доказательствами.
@"game-designer (agent)" посчитай, за сколько дней новый игрок при 3 боях в день получает первую эпическую карту и уровень 3 у стартовой колоды. Таблица и вывод.
@"tech-artist (agent)" нарисуй иконки для четырёх вкладок «Снабжения» в семействе TerraIcons95, покажи их на тёмном фоне в обычном и активном состоянии.
@"ux-ui (agent)" перестрой экран «Ещё»: одно главное действие, остальное по частоте использования. Без нумерации, капслок-надзаголовков и стрелок в каждой кнопке.
```

## Если ход остановился на полпути

```
В docs/TASKS.md остались открытые пункты: <перечисли>. Продолжай с ними. Если что-то заблокировано, напиши, чем именно.
```
