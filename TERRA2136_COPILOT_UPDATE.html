Применение пакета

Прочитать исходный HTML и извлечь распаковщик во временную папку. В handoff указать реальный путь к этому файлу.

from pathlib import Path
import re
import tempfile

handoff = Path("TERRA2136_COPILOT_UPDATE.html").resolve()
source = handoff.read_text(encoding="utf-8")
match = re.search(r'<script id="terra-installer" type="text/plain">(.*?)</script>', source, re.S)
if match is None:
    raise RuntimeError("В исходном HTML не найден terra-installer")
installer = Path(tempfile.mkdtemp(prefix="terra-copilot-")) / "apply_readme.py"
installer.write_text(match.group(1), encoding="utf-8")
print(installer)

Запуск из терминала. Пути заменить фактическими; python при необходимости заменить на python3 или py.

python "/путь/к/apply_readme.py" "/путь/к/TERRA2136_COPILOT_UPDATE.html" check --repo "/путь/к/репозиторию"
python "/путь/к/apply_readme.py" "/путь/к/TERRA2136_COPILOT_UPDATE.html" apply --repo "/путь/к/репозиторию"
python "/путь/к/apply_readme.py" "/путь/к/TERRA2136_COPILOT_UPDATE.html" verify --repo "/путь/к/репозиторию"

Если Copilot работает в собственной ветке задачи, основанной на целевой, добавь к каждой команде --work-branch "имя-ветки". Локальная ссылка на целевую ветку должна существовать; при её отсутствии сначала получи её обычным git fetch. Для иной существующей сборки добавь --build "TERRA2136_PLAY_vX.Y.Z.html". Резервные копии заменяемых файлов сохраняются во временную папку; путь выводится в результате apply. Сам распаковщик не делает commit, push или merge.

Режим export --out "новая-пустая-папка" извлекает точную копию пакета без проверки Git и без изменения репозитория. verify проверяет установленный пакет, а check — данные, пути и план изменения.
