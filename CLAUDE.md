# TERRA 2136 — правила проекта для Claude Code

Офлайн tower offense в одном HTML-файле (~43 МБ, WebGL2, без сети). Автор и заказчик — Максим.
Отвечай по-русски. Код, идентификаторы и комментарии в коде — по-английски, как в проекте.

## Карта исходников

Рабочая копия — папка `parts/`, а не HTML. HTML всегда собирается заново.

| Часть | Что внутри | Правим? |
|---|---|---|
| `markup/head.html`, `markup/body.html` | `<head>`, каркас меню/боя/модалок | да |
| `css/00-base.css` | 241 КБ наслоенных версий стилей | только точечно |
| `css/01…09-*.css` | стили модулей 78–91 | да |
| `css/10-polish95.css` | слой полировки v0.95 (последний = побеждает) | да, сюда новые правила UI |
| `ui/controller.js` | меню, бой, ввод, `renderMenu`, `drawDock`, `refreshHUD`, `frame` | да |
| `ui/views.js` | шаблоны экранов (`hq`, коллекция, награды, модули…) | да |
| `ui/version95.js` | `globalThis.TERRA_VERSION` — единственный номер версии | при релизе |
| `ui/icons95.js` | `TerraIcons95`: иконки навигации и эмблема | да |
| `game/content-sim.js` | `TerraSim`, кампания, цели, правила | осторожно (см. инварианты) |
| `game/progress.js` | `TerraProgress`: кошелёк, кейсы, терминал, сохранения | осторожно |
| `render/*.js`, `engine/*.js` | рендер, модели, анимации, модульный бандл ArkVisual | да, только визуал |
| `data/design-config.js` | `TERRA_BALANCE`, `TERRA_PROGRESSION`, лут, фракции, раскладки | только по задаче баланса |
| `data/assets-models.js`, `data/mortarch-models.js`, `data/ui-images.js`, `data/texture-data.js` | base64-картинки и GLB | не открывать целиком, не править руками |

Большие `data/*` файлы читай через `grep -o` с узким шаблоном или через `python3` со срезами. Никогда не выводи их целиком.

## Команды

```
python3 tools/split.py TERRA2136_PLAY_vX.html parts/      # один раз из готового HTML
python3 tools/build.py parts/ dist/TERRA2136_PLAY.html     # собрать
python3 tools/check.py dist/TERRA2136_PLAY.html            # node --check всех <script>
python3 qa/qa.py dist/TERRA2136_PLAY.html --out qa-out --no-battle          # меню, 2 разрешения
python3 qa/qa.py dist/TERRA2136_PLAY.html --out qa-out --battle-only --viewports mobile
python3 tools/patch.py patches/vX_Y_Z parts/               # применить набор патчей
```
На Windows вместо `python3` — `py`. Финальная строка QA: `QA RESULT: PASS|FAIL`, подробности в `qa-out/report.json`, скриншоты рядом.

## Инварианты (нарушение = откат)

1. Симуляция детерминирована: 20 Гц, фиксированный шаг, сид. Модули с пометкой «presentation only / render-only» не читают `Math.random`/`Date.now` для геймплея и не пишут в `sim.s`.
2. Кошелёк меняется только через транзакции `TerraProgress` (candidate → write → accept). UI никогда не начисляет награды сам.
3. Формат сохранения и экспорта JSON обратно совместим. Новые поля — опциональные, со значением по умолчанию.
4. Один файл, без сети: никаких внешних шрифтов, CDN и запросов. Новые картинки — встроенные SVG или сжатый webp в `data:`.
5. Номер версии — только `ui/version95.js` + `<title>` + `markup/body.html`. Больше нигде не хардкодить.
6. Изменения баланса (`data/design-config.js`) — только в задаче баланса, с таблицей «было → стало» в `docs/CHANGELOG.md`.

## Как вносить изменения

- Одна задача = одна тема. Перед правкой найди точное место (`grep -n`), после — `build → check → qa`.
- Новые правила UI кладутся в `css/10-polish95.css` (или новый `css/NN-*.css` для следующей версии), а не в `00-base.css`.
- Клики в меню обрабатываются делегированием на `document` через `closest('button')` и `data-*`. Новые кнопки получают `data-*`, свои `addEventListener` не нужны.
- Повторяемые правки оформляй патчем в `patches/vX_Y_Z/spec.py`: он падает, если якорь не найден ровно N раз.
- Каждая правка кода получает короткий комментарий-метку версии в стиле проекта: `/* HQ-095: почему */`.

## Визуальный язык

Палитра: фон `#071b23`, поверхность `#0a2932`, линия `rgba(99,206,219,.32)`, циан `#84dfdc`, золото `#f4cc79`, красный `#ef977d`, текст `#eef5ef`, вторичный `#9dafb1`.
Иконки интерфейса: сетка 24 px, обводка 1.8, скруглённые концы; активное состояние — заливка `currentColor` 20 %. Ресурсы и кейсы остаются растровыми (`TerraArt55`).
Минимумы: текст 11 px (в бою 10 px), цель касания 44 px, контраст текста ≥ 4.5:1.
Не использовать: кремовый фон, моноширинные подписи, нумерацию «01/02/03» там, где нет последовательности, акцент одного слова курсивом, стрелку «→» в каждой кнопке, новые капслок-надзаголовки над каждым блоком, одинаковые скруглённые карточки с одной и той же тенью для всего подряд.

## Как работать

- Делай задачу в заданном объёме. Типовые решения принимай сам. Спрашивай только если разные прочтения задачи ведут к разной работе.
- Если видишь ошибку в самой задаче — скажи одной фразой и продолжай как просили.
- Не заканчивай ход сводкой, которая объявляет следующий шаг, не выполнив его. Останавливайся, только когда без Максима дальше двигаться нельзя.
- Субагентов запускай только на крупные независимые куски (например, «проверить все 82 карты»). Мелочь, которую можно сделать за несколько вызовов, делай сам.
- Итоговый отчёт: первой фразой — что сделано и каков результат QA; затем список изменённых файлов; затем что не сделано и почему.
- Документы пиши по объёму задачи, без вводных разделов и повторов.
