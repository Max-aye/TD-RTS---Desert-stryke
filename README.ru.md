## Обзор

TERRA 2136 — компактная тактическая стратегия о враждебном марсианском фронтире. Игра сочетает:

- бой в реальном времени в формате tower defense / RTS;
- кампанию, миссии и развитие карты;
- модули, улучшения, награды и системы игрока;
- mobile-first интерфейс и адаптивные экраны;
- WebGL2-рендеринг в одной автономной офлайн-сборке.

Проект задуман одновременно как playable-игра и техническое портфолио: он показывает, как организовать браузерную игру с разделёнными исходниками, детерминированной симуляцией, инженерией UI и автоматической QA-проверкой в одном репозитории.

## Быстрый запуск

### Запустить игру сразу

1. Откройте [`index.html`](./index.html).
2. Нажмите кнопку запуска на landing page.
3. Или откройте готовую сборку: [`TERRA2136_PLAY_v0.95.0.html`](./TERRA2136_PLAY_v0.95.0.html).

Backend, аккаунт и внешний CDN не нужны.

### Локальный HTTP-просмотр

```bash
python3 -m http.server 8000
```

Затем откройте <http://localhost:8000/>.

## Технические особенности

### Игровые системы

- детерминированная симуляция боя с фиксированным шагом;
- кампании, миссии, прогрессия и карта;
- локальное сохранение и транзакции ресурсов;
- mobile-first UI с адаптацией под разные размеры экранов;
- автономная доставка одним HTML-файлом без внешних runtime-зависимостей.

### Инженерный подход

- исходники разделены на модули перед финальной сборкой;
- автоматическая проверка синтаксиса через `node --check`;
- Playwright-проверка интерфейса и smoke-тест боя;
- версионные патчи для контролируемых изменений;
- документация, design notes и roadmap как часть рабочего процесса.

## Сборка и проверка

### Требования

- Python 3.11+
- Node.js 20+
- Git
- Playwright для UI-автоматизации

### Собрать игру

```bash
python3 tools/build.py parts/ dist/TERRA2136_PLAY.html
```

### Разделить исходный HTML на `parts/`

```bash
python3 tools/split.py TERRA2136_PLAY_v0.95.0.html parts/
```

### Проверить синтаксис

```bash
python3 tools/check.py dist/TERRA2136_PLAY.html
```

### Запустить UI QA и smoke-тест

```bash
python3 -m pip install playwright
python3 -m playwright install chromium

python3 qa/qa.py dist/TERRA2136_PLAY.html --out qa-out --no-battle
python3 qa/qa.py dist/TERRA2136_PLAY.html --out qa-out --battle-only --viewports mobile
```

Проверяются переходы меню, touch-target, переполнение, читаемость интерфейса и стабильность запуска боя.
