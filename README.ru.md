## Обзор

TERRA 2136 — компактный прототип тактической стратегии на враждебном марсианском фронтире. Игра объединяет:

- боевые действия в ре��льном времени в формате tower defense / RTS;
- развитие кампании и карты;
- модульные улучшения, награды и системы игрока;
- mobile-first интерфейс и адаптивную вёрстку;
- рендеринг WebGL2 и единую офлайн-сборку.

Проект создан одновременно как игра и техническая демонстрация: он показывает организацию браузерной игры с раздельными исходными файлами, детерминированной логикой симуляции, инженерией интерфейса и автоматизированной проверкой качества.

## Быстрый старт

### Немедленный запуск

1. Откройте [`index.html`](./index.html).
2. Запустите игру с landing page.
3. Либо откройте готовую сборку напрямую: [`TERRA2136_PLAY_v0.97.1.html`](./TERRA2136_PLAY_v0.97.1.html).

Серверная часть, учётная запись и внешний CDN не требуются.

### Локальный HTTP-просмотр

```bash
python3 -m http.server 8000
```

Затем откройте <http://localhost:8000/>.

## Технические особенности

### Игровые системы

- детерминированная симуляция боя с фиксированным шагом;
- течение кампании, развитие и структура миссий;
- локальное сохранение и транзакции ресурсов;
- mobile-first UI с адаптацией под разные размеры экрана;
- поставка в одном HTML-файле без внешних runtime-зависимостей.

### Инженерная дисциплина

- разделение исходников на модули перед финальной сборкой;
- автоматическая проверка синтаксиса через `node --check`;
- Playwright-проверка интерфейса и smoke-тесты;
- версионируемый процесс применения патчей;
- разработка с опорой на документацию, заметки по дизайну и roadmap.

## Сборка и проверка

### Требования

- Python 3.11+
- Node.js 20+
- Git
- Playwright для автоматизации UI

### Сборка игры

```bash
python3 tools/build.py parts/ dist/TERRA2136_PLAY.html
```

### Повторное разделение HTML-файла на исходники

```bash
python3 tools/split.py TERRA2136_PLAY_v0.97.1.html parts/
```

### Проверка синтаксиса

```bash
python3 tools/check.py dist/TERRA2136_PLAY.html
```

### UI QA / smoke-тест

```bash
python3 -m pip install playwright
python3 -m playwright install chromium

python3 qa/qa.py dist/TERRA2136_PLAY.html --out qa-out --no-battle
python3 qa/qa.py dist/TERRA2136_PLAY.html --out qa-out --battle-only --viewports mobile
```

Проверяются сценарии меню, размеры touch-target, переполнение, читаемость интерфейса и стабильность запуска боя.
