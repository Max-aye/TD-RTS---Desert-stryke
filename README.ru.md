## 🎮 Это не обычная стратегия

</div>

### Твоя задача — **система, а не солдаты**

В TERRA 2136 ты не кликаешь по каждому юниту. Вместо этого ты:
- **Строишь производителей**, которые автоматически выпускают отряды
- **Выбираешь боевые карты**, которые превращаются в укрепления и тактические инструменты
- **Управляешь маршрутом** вдоль трёх постов, переключая внимание между фронтами
- **Применяешь умения поддержки** в правильный момент, чтобы прорвать оборону или срочно защитить

Результат: игра остаётся **читаемой на экране 390 px**, но стратегия требует настоящих решений.

## ⚡ Механика, которая работает

### Боевой цикл: один ход — одно решение

```
[Колода] → [Выбери 6 карт + 2 умения] → [Три поста] → [Три площадки на каждом]
           ↓
[Маршрут атаки] → [Автоматические отряды идут вперёд] → [Центральный маяк даёт +6 кредитов/сек]
           ↓
[Удерживай / Прорывайся / Сопровождай / Эвакуируй] → [Получи награды] → [Развивай колоду]
```

| 🃏 **Коллекция** | 82 карты, 4 редкости, 3 фракции | Неограниченные комбинации колод |

| 🎯 **Специализации** | Настрой роль каждой карты | Одна карта — много вариантов |

### Один файл. Полная независимость.

**43 МБ HTML-файл** содержит:
- ✅ Полный 3D-движок WebGL 2
- ✅ 82 боевые карты с моделями
- ✅ 50 операций кампании

- ✅ Детерминированную симуляцию
- ✅ Локальное хранилище профилей

**Без интернета. Без аккаунтов. Без сервера.**

### Архитектура

```
JavaScript (игра) + HTML/CSS (интерфейс) + WebGL 2 (рендер)
        ↓
Фиксированный шаг 20 Hz (детерминированность)
        ↓
Встроенные ассеты (нет CDN)
        ↓
Локальное хранилище (JSON сохранения)
```

### Для разработчиков

```bash
# Распаковать исходники
python3 tools/split.py TERRA2136_PLAY_v0.99.2.html parts/

# Собрать назад
python3 tools/build.py parts/ dist/TERRA2136_PLAY.html

# Проверить синтаксис
python3 tools/check.py dist/TERRA2136_PLAY.html

# QA: меню и интерфейс
python3 qa/qa.py dist/TERRA2136_PLAY.html --out qa-out --no-battle

# QA: боевой режим
```
